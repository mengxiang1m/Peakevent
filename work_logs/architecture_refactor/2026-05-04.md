- 修改内容:
  - 新增 Hybrid v2.1 structured temporal head: onset + duration classification + apex offset, 约束 apex 落在 event span 内。
  - Hybrid decoder 训练期 refinement 支持 matched-order teacher forcing: 用 proposal 与 GT 的 Hungarian 匹配顺序组织 causal refinement；推理期仍按预测 onset/top-K 顺序。
  - Count head 不再只是可创建模块: 训练和验证 loss 都接入 count CE；推理阶段可用 count logits 做 top-K event decoding，减少固定 threshold 依赖。
  - 保留 `hybrid_time_head=independent` 兼容旧连续 onset/apex/duration 头。
  - 更新 v2.1 远程实验脚本，输出到 `*_hybrid_v21_ablation`，避免覆盖或跳过旧 `*_hybrid_ablation` 结果。
  - 汇总脚本新增 v2.1 summary 输出: `hybrid_v21_ablation_summary.*` 与 `hybrid_v21_calibrated_summary.*`。

- 架构意图:
  - 解决当前 Hybrid 结果中 F1 可被校准拉高、但 Onset/Apex MAE 明显落后旧 AR 的问题。
  - 将旧 AR 的结构合法性与 apex-offset 先验迁移到 DETR-style event head 中，而不是回退到两阶段 AR baseline。
  - 让 AR 成为 Hybrid decoder 内部顺序 refinement 机制，不作为独立对照或消融分支。

- 远程验证需求:
  - 先在远程 VM 跑 single-batch smoke，确认 structured head、matched-order refinement、count loss、generate/top-K 输出全部连通。
  - 再跑 WLEL `H0_v21_hybrid_s42` 与 `HNC_no_count_head_s42`、`HID_independent_time_s42`，优先观察 F1、precision/recall 平衡、Onset MAE 是否向旧 G0 的 0.747 靠近。
  - 本机不运行训练、评估或 GPU 任务；本次仅做代码编辑与静态检查。

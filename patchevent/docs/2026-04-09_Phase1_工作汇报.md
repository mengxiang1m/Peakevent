## 一、Phase 1 定位与目标

Phase 1 是 PatchEvent 两阶段框架的**表征学习阶段**。其核心目标是：

> 在 patch 粒度上，通过多任务事件感知预训练，让 Transformer Encoder 学会识别时间序列中的峰值事件模式——**哪里有峰、离峰多远、处于什么阶段、峰值在 patch 内的精确位置**——为下游 Phase 2 解码器提供高质量的 encoder memory。

**设计出发点**：直接让 decoder 从原始信号中同时学习特征提取和事件生成是困难的。Phase 1 预训练提供的核心价值在于**时间定位先验**（temporal localization prior）——后续消融实验证明，没有预训练的编码器虽然能达到相近的事件检测 F1，但 OnsetMAE（事件起始时间误差）劣化 31-41%。

|--------|-------|-----|------|

### 2.3 点级数据格式

原始序列 CSV（`wlel_event_series_v1.csv`）每行一个时间点：

| 字段 | 说明 |
|------|------|
| `timestamp` | 时间戳（小时级） |
| `value` | 原始数值（如负荷MW、温度℃） |
| `is_peak` | 是否为峰值点（0/1） |
| `d_to_apex` | 到最近峰值的距离（小时） |
| `is_peak_event` | 是否属于峰值事件 |
| `phase` | 事件阶段（background / rising / apex / falling） |
| `split` | 数据集划分（train / val / test） |

### 2.4 事件提取流程

事件从原始时间序列中通过 `build_wlel_events.py`（及 ETT/ELC 对应脚本）提取：

1. **时间线统一**：补全缺失时间点（线性插值），确保严格 1 小时间隔
2. **动态阈值计算**：基于滑动窗口分位数（enter_quantile=0.95, exit_quantile=0.90）的自适应峰值检测
3. **事件边界确定**：采用 `gradient_width` 模式 —— 以峰值点为锚点，向两侧扩展直到变化率低于阈值（`rate_frac × apex_value`），每侧最大 3 小时、最小 1 小时
4. **事件合并**：间隔 ≤1 小时的相邻事件合并
5. **最小持续时长过滤**：事件持续时长 < 3 小时的被过滤

### 2.5 Patch 级标签生成

关键创新点——将点级标签聚合为 **patch 级软标签**，用于 encoder 的多任务预训练。

**Patch 参数**：patch_len=8, stride=4 → 每 96 小时窗口产生 **23 个 patch**（带 50% overlap）。

Patch 标签文件（`wlel_patch_labels_v1.csv`）每行对应一个 patch：

| 字段 | 说明 | 取值范围 |
|------|------|----------|
| `has_apex` | 该 patch 是否包含峰值 | 0 或 1 |
| `apex_offset` | 峰值在 patch 内的位置 | 0-7（无峰值时为 -1） |
| `min_d_to_apex` | 到最近峰值的最小距离 | ≥ 0 |
| `phase_dist_bg/rising/apex/falling` | 4 类阶段的软分布 | 概率分布，和为 1 |
| `apex_intensity` | 峰值强度 | 原始值（无峰值时为 -1） |

**示例**（WLEL 第一天）：
```
patch_start=0h:  has_apex=0, offset=-1, min_d=3, phase=[1.0, 0.0, 0.0, 0.0]  — 纯背景
patch_start=4h:  has_apex=1, offset=6,  min_d=0, phase=[0.5, 0.25, 0.125, 0.125] — 含峰值
patch_start=8h:  has_apex=1, offset=2,  min_d=0, phase=[0.375, 0.25, 0.125, 0.25] — 含峰值
```

### 2.6 数据归一化

采用 **per-dataset z-score 归一化**：均值和标准差仅从训练集计算，验证/测试集使用相同统计量。这对处理不同域之间的数值差异（如 WLEL~5000MW vs ETT~27℃）至关重要。

## 三、模型架构

### 3.1 整体流程

```
输入: x (B, 96)  — 归一化后的 96 小时序列
  │
  ├─ Unfold(patch_len=8, stride=4) → patches (B, 23, 8)
  │
  ├─ Linear(8 → 128) + Sinusoidal PE + LayerNorm → z (B, 23, 128)
  │
  ├─ 2-layer Transformer Encoder (FullAttention, d_model=128, n_heads=4, d_ff=256)
  │                                                    → z (B, 23, 128)
  │
  └─ 4 个预测头:
       ├─ has_apex_head:    Linear(128→1) → sigmoid  → (B, 23)     峰值存在性
       ├─ d_to_apex_head:   Linear(128→1) → ReLU     → (B, 23)     距离回归
       ├─ phase_dist_head:  Linear(128→4) → softmax  → (B, 23, 4)  阶段分布
       └─ apex_offset_head: Linear(128→8) → raw logit → (B, 23, 8) 偏移分类
```

### 3.2 核心组件详解

#### (a) Patch Embedding

将每个 8 维 patch 通过线性投影映射到 128 维空间：
- `patch_embed = nn.Linear(8, 128)`
- 加上**正弦位置编码**（非可学习），为每个 patch 注入位置信息
- 经过 LayerNorm 归一化

#### (b) Transformer Encoder

标准的 2 层 Transformer Encoder：
- **Full Attention**（无因果掩码），每个 patch 可以看到所有其他 patch
- 4 头注意力，d_model=128，d_ff=256
- 激活函数 GELU，dropout=0.1
- 梯度裁剪 max_norm=1.0

#### (c) 四个预测头

每个头是一个简单的线性层，从 128 维 patch 表征映射到对应标签空间。

#### (d) 辅助模块（可选）

- **NPP (Next-Patch Prediction)**：`npp_head = Linear(128→8)`，预测下一个 patch 的原始值。用于多域联合训练时的正则化。
- **MPR (Masked Patch Reconstruction)**：随机遮蔽部分 patch，从恢复的表征重建原始 patch 值。借鉴 PatchTST 的思路。

### 3.3 模型规模

| 组件 | 参数量 |
|------|--------|
| Patch Embedding | 1,152 |
| LayerNorm | 256 |
| Transformer Encoder (2 层) | 265,216 |
| 预测头（5 个） | 2,838 |
| **总计** | **~269K** |

模型非常轻量，仅 **27 万参数**。

### 3.4 设计出发点

1. **为什么用 Patch 而不是逐点？** Patch 粒度提供了局部上下文（8小时 ≈ 一个事件的覆盖范围），且大幅减少序列长度（96→23），降低计算成本。
2. **为什么 4 个预训练任务？** 每个任务捕捉事件的不同方面：
   - `has_apex`：二分类，学习峰值的存在性感知
   - `d_to_apex`：回归，学习距离峰值的连续距离感知
   - `phase_dist`：软分布预测，学习事件各阶段的细粒度识别
   - `apex_offset`：8 类分类，学习峰值在 patch 内的精确位置定位
3. **为什么 stride=4（50% overlap）？** 相邻 patch 有 50% 重叠，确保每个时间点都被至少 2 个 patch 覆盖，避免边界处的信息缺失。

## 四、损失函数设计

### 4.1 复合损失

$$L = \lambda_{bce} \cdot L_{bce} + \lambda_d \cdot L_d + \lambda_{kl} \cdot L_{kl} + \lambda_{off} \cdot L_{off}$$

默认权重：$\lambda_{bce}=1.0, \lambda_d=0.5, \lambda_{kl}=1.0, \lambda_{off}=0.5$

### 4.2 各项损失详解

| 损失 | 对应任务 | 公式 | 设计考量 |
|------|----------|------|----------|
| **Focal BCE** | has_apex | $-(1-p_t)^\gamma \log(p_t)$, $\gamma=2.0$ | 峰值 patch 占比低（~15-20%），Focal Loss 降低易分类背景 patch 的权重 |
| **Smooth L1** | d_to_apex | $\text{SmoothL1}(\hat{d}, d)$ | 比 MSE 对异常值更鲁棒 |
| **Weighted KL** | phase_dist | $\sum_c w_c \cdot p_c \log(p_c/\hat{p}_c)$ | 权重 [1, 1, 2, 2]，强调稀有的 apex/falling 阶段（bg 占 ~99.7%） |
| **Masked CE** | apex_offset | CE with label_smoothing=0.1 | 仅对 has_apex=1 的 patch 计算；label smoothing 防止过拟合 |

### 4.3 辅助损失（可选）

| 损失 | 权重 | 公式 | 用途 |
|------|------|------|------|
| **NPP** | $\lambda_{npp}=0.5$ | MSE(npp_pred, next_patch) | 多域联合训练正则化 |
| **MPR** | $\lambda_{recon}$ | MSE(recon, masked_patch) | 自监督增强（实验性） |

### 5.2 训练模式

1. **单域训练**（推荐）：每个域独立训练一个 encoder。3 域 × 3 seeds = **9 个实验**。
2. **多域联合训练**：将 3 个域的数据合并训练，采用 per-dataset 归一化消除分布差异，加 NPP 正则化。3 seeds = **3 个实验**。

| phase_dist（软分布） | Cosine Similarity, KL Divergence | Per-class MAE, Event F1 |

### 6.3 Phase 1 子任务消融实验（WLEL, 3 seeds）

通过逐一去除预训练损失项，验证每个任务的贡献：

| 配置 | has_apex F1 | d_to_apex MAE | phase CosSim | offset Acc |
|------|-------------|---------------|--------------|------------|
| **P0 Baseline（完整）** | **0.920** | **0.197** | **0.966** | **0.810** |
| P1a: 去掉 has_apex | 0.000 ↓ | 0.222 ↓ | 0.962 | 0.794 |
| P1b: 去掉 d_to_apex | 0.916 | 0.655 ↓↓ | 0.965 | 0.807 |
| P1c: 去掉 phase_dist | 0.915 | 0.205 | 0.680 ↓↓ | 0.808 |
| P1d: 去掉 apex_offset | 0.913 | 0.200 | 0.964 | 0.104 ↓↓ |

**关键发现**：

1. **去掉任何一个任务，对应指标都会显著退化**，验证了 4 个任务各自不可替代。
2. **has_apex 是基础**：去掉后 F1 直接降到 0（因为没有训练这个头），同时影响其他任务。
3. **各任务有协同效应**：去掉 has_apex 后，d_to_apex MAE 也劣化（0.197→0.222），说明峰值存在性感知有助于距离回归。
4. **去掉 apex_offset** 对 Phase 2 影响最大 —— 后续 Phase 2 消融证明，去掉 offset 后 OnsetMAE 劣化 7.4%，是单个对 Phase 2 时间定位贡献最大的子任务。

ETT 和 ELC 上也进行了同样的 5 组消融（P1a-P1d + P1e_generic_npp），每组 3 seeds，共 30 个实验。消融趋势与 WLEL 一致，进一步验证了结论的跨域鲁棒性。

## 七、Phase 1 对 Phase 2 的核心价值

Phase 1 预训练对 Phase 2 的贡献不在于事件检测能力（F1），而在于**时间定位先验**：

| Phase 2 Encoder 模式 | F1 | OnsetMAE |
|----------------------|-----|----------|
| Frozen Phase1 Encoder（推荐） | 0.841 | **0.747** |
| Scratch（同架构无预训练） | 0.831 | 0.992 (+33%) |
| CNN Encoder | 0.826 | 0.996 (+33%) |
| LSTM Encoder | 0.839 | 1.050 (+41%) |
| MLP Encoder | 0.835 | 0.975 (+31%) |

**结论**：所有非预训练编码器（CNN/LSTM/MLP/Scratch）能达到相近的 F1（0.83 左右），但 OnsetMAE 均比预训练编码器差 31-41%。这证明 Phase 1 预训练的核心价值是**时间定位先验**——让编码器学会精确感知峰值在时间轴上的位置。

## 九、总结

1. **Phase 1 成功构建了事件感知的时序表征**：在三个工业数据集上，峰值检测 F1 达 0.91-0.92，阶段分布余弦相似度 > 0.96，偏移分类准确率 0.77-0.88。

2. **四个预训练任务各有不可替代的贡献**：消融实验证明去掉任何一个任务都会导致对应指标显著退化，且任务之间存在协同效应。

3. **预训练的核心价值在于时间定位先验**：Phase 1 encoder 为 Phase 2 decoder 提供的不仅是"什么模式"的语义信息，更重要的是"在什么位置"的精确时间坐标。

4. **模型轻量高效**：仅 ~269K 参数，50 epoch 内收敛（通常 Early Stopping 在 20-30 epoch 触发），单域训练耗时短。

5. **跨域表现一致**：模型设计在 WLEL、ETT、ELC 三个不同特性的工业数据集上均表现稳定，验证了方法的通用性。

### 10.6 与 PatchEvent 的潜在关联

该数据集对 PatchEvent 框架有以下潜在价值：

1. **大规模跨域验证**：目前 PatchEvent 仅在 3 个数据集上验证，该数据集提供 43 个电力市场、跨 4 大洲的多样化负荷数据，可大幅扩展验证范围。
2. **多尺度时间分辨率**：包含 5分钟 ~ 1小时多种频率，可研究 PatchEvent 在不同时间粒度下的适应性。
3. **长序列评估**：最长达 24 年（NYISO），可验证事件检测在超长序列上的鲁棒性和季节变化适应能力。
4. **多区域并行数据**：日本 9 区、澳大利亚 5 州的并行负荷数据，可用于跨区域联合预训练和迁移学习实验。
5. **公开可复现**：CC BY 4.0 许可，标准化格式，适合发表论文时作为公开 benchmark。

**注意**：使用前需将数据统一重采样至 1 小时频率（与 PatchEvent 当前设计匹配），并进行事件标注（峰值检测 + 事件提取）。

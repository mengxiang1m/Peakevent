# 科研绘图色彩与可视化规范 (Scientific Plotting & Color Guidelines)

本规范基于人类视觉感知原理制定，旨在确保复杂数据（如模型权重分布、时间序列预测对比、注意力机制热力图等）在可视化时的准确性、易读性和学术专业性。核心设计哲学为：“首先，不造成伤害” (Above all, do no harm)。

## 1. 核心配色“黄金法则” (Golden Rules for the Colorist)

* **控制数量**：图表中使用的离散颜色数量应尽量少，理想情况下控制在 6 种左右，以防视觉疲劳。
* **名称区分度**：选用的颜色在视觉和语义（即人们对颜色的命名习惯）上应具有高区分度，减少分类重叠和视觉歧义。
* **灰度兼容性**：必须确保图表在黑白（灰度）打印模式下依然能够清晰传达核心特征与对比关系。
* **无障碍设计**：配色方案必须考虑色盲/色弱群体的视觉需求（如避免纯红-纯绿的直接对比）。

## 2. 严禁使用“彩虹色带” (The "Anti-Rainbow" Rule)

在任何热力图、等高线图或连续特征映射中，**坚决避免使用彩虹色带（如 Matplotlib 中的 `jet` colormap）**。

* **缺乏自然顺序**：彩虹色（红橙黄绿青蓝紫）的色相变化不符合人类对大小或轻重缓急的自然认知规律。
* **伪分类切割**：人类视觉会下意识地将连续的彩虹色段错误地分割成不同的离散类别，破坏数据的连续性。
* **亮度误导**：彩虹色中不同颜色的明度（Lightness）变化是无规律跳跃的，会错误地在视觉上强调某些并不重要的数据点。
* **丢失高频细节**：彩虹色带中的低亮度颜色（如深蓝色）极易掩盖数据中的高频、微小但重要的细节。

## 3. 基于数据类型的色彩映射 (Mapping Data to Color)

### 3.1 连续型数据 (Sequential Data)
适用于单向增长的数值（如绝对误差、方差、概率值等）。
* **推荐方案**：采用色相-明度渐变（Hue-Lightness）的连续色带。
* **映射规则**：将较高的数据值映射为较暗/较深的颜色。
* **层级控制**：如果需要离散化映射以便于观测阶梯变化，建议将颜色阶梯控制在 3 到 9 个层级（steps）。
* **平滑过渡**：如果使用双色相混合，应确保相邻色相能良好插值，并始终伴随亮度的单向改变。

### 3.2 发散型数据 (Diverging Data)
适用于存在具有实际意义的“中点”的数据（如预测值与真实值的残差、正负权重、相关系数等）。
* **中点处理**：关键的“中点”（如 0 值或平均值）必须使用中性的灰色或极低饱和度的浅色。
* **极值处理**：正负两端的极端值应使用饱和度高的颜色，且必须分配完全不同的色相（Hues）以作鲜明区分。

## 4. 色彩空间的选择 (Color Space Engineering)

在代码中进行复杂的颜色插值、融合或生成调色板时：
* **弃用伪感知模型**：不要使用 HLS、HSV 或 HSB 模型进行数值的直接映射。它们仅仅是对物理设备 RGB 空间的简单数学重构，无法准确预测人类实际感知的亮度差异。
* **使用感知均匀色彩空间**：应采用基于人类视觉对立过程（Opponent processing）建立的 CIE LAB 或 CIELUV 空间进行计算。
    * **L*** 表示亮度 (Luminance)。
    * **a*** 表示红-绿对比度。
    * **b*** 表示黄-蓝对比度。

## 5. 警惕视觉上下文干扰 (Contextual Visual Effects)

图形元素的最终感知结果不仅取决于该点本身的数值，还受其周围视觉环境的强烈影响：
* **同时对比效应 (Simultaneous Contrast)**：相同的颜色在不同背景下看起来会截然不同。
* **散布效应 (Spreading)**：在细线条（如多条折线图）、小点（散点图）或密集网格中，相邻颜色会发生视觉融合。
* **设计对策**：在绘制极细粒度的图表元素时，需适当增加亮度对比度，或预留充足的空间，避免深色背景“吞噬”数据点。
